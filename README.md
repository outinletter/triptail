# TripTail

여행 사진을 ChatGPT 웹 프로젝트에 올리기 좋게 정리하고, 블로그용 HTML 결과를 다시 붙여넣어 저장하는 보조 웹 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 사진을 올리고 여행 정보를 입력한 뒤 `업로드 준비하기`를 누르면 ChatGPT에 붙여넣을 요청문이 만들어집니다. `ChatGPT 열기` 버튼은 외부 브라우저에서 ChatGPT 웹을 엽니다.

## 다음 단계

ChatGPT가 만든 HTML을 앱 하단에 붙여넣으면 미리보기, 복사, 다운로드를 할 수 있습니다. API 키 없이 쓰는 흐름이므로 사진 분석과 글 작성은 ChatGPT 웹 프로젝트에서 직접 진행합니다.
