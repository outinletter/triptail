기기 내 처리

선택한 사진은 기기에서 축소하고 원본 GPS는 분석용 사진에서 제거하며 지도 확인·검색에 사용하는 경우 아래와 같이 처리합니다. 웹 앱은 사진, 글, API 키를 영구 저장하지 않습니다. 웹 페이지를 닫으면 작업 내용이 사라집니다. 네이티브 앱의 저장한 글은 기기에 보관되며 보관함에서 삭제할 수 있습니다. 기기 백업에 글이 포함될 수 있습니다.

외부 서비스 전송

매 작업에서 동의를 받은 뒤 Cloudflare의 TripTail 서버를 통해 Google Vision에 축소 사진을 장소·글자 인식 용도로, DeepSeek에 축소 사진·여행 정보·선택한 자료를 글 작성 용도로, Wikipedia에 확인한 장소명을 검색 용도로 전달합니다. 원본 GPS 메타데이터는 사진 재인코딩으로 제거합니다. 직접 입력한 메모나 사진 내용에 위치·개인정보가 포함될 수 있으므로 전송 전에 확인해주세요.

앱 서버에는 글이나 사진을 저장하는 기능이 없습니다. 외부 업체의 요청·운영 로그, 보관 및 삭제 정책은 아래 정책을 따릅니다. 외부 업체의 보관 기간과 데이터 처리 조건은 운영자가 출시 전에 확정해야 합니다. 전송한 자료를 앱에서 회수할 수는 없으며 삭제 문의는 지원 이메일로 보내주세요. 다음 요청에서 취소하면 추가 전송되지 않습니다.

iOS 사진 위치와 지도 확인

아이폰 앱은 선택한 사진의 EXIF 촬영 날짜·시간과 GPS를 기기에서 읽습니다. 사진 GPS는 지역명 조회 시 Apple에 전달하며 Google 지도에서 촬영 위치를 표시하거나 Apple 지도에서 주변 장소를 검색하는 범위에 사용할 수 있습니다. 지도 열기와 검색 시 장소명·검색어·해당 좌표 또는 검색 범위가 지도 제공 업체에 전달됩니다. 현재 위치 권한은 요청하지 않습니다. 사진을 분석하는 Google Vision·DeepSeek에는 GPS가 제거된 축소 사진을 보내고 촬영 날짜·확인한 장소·촬영 대상과 자료만 별도로 사용합니다. 촬영 시간은 기기 내 확인 화면에 표시합니다. 원본 사진과 GPS는 보관함에 저장하지 않습니다.

선택과 삭제

사진 제거 또는 페이지 종료로 작업 데이터를 지울 수 있습니다. API 키는 브라우저에 저장하지 않습니다. 웹 캐시는 앱 화면 파일을 저장합니다. 브라우저의 사이트 데이터 삭제로 제거할 수 있습니다. 광고와 추적 SDK, 계정 기능은 없습니다. 공유 또는 다운로드한 글은 사용자가 직접 관리합니다.
